What is FixFlow?

FixFlow is a centralized service request and workflow management platform designed to digitize the complete lifecycle of service requests.

The Problem

Traditional service management involves manual requests, unclear ownership, delayed communication, poor tracking, lack of accountability, and difficult administration.

The FixFlow Solution

We replace chaos with a deterministic state-machine workflow powered by strict Role-Based Access Control and a unified dashboard for all participants.

Digital Lifecycle

User submits a structured service request
Admin reviews, categorizes & assigns
Technician processes & resolves the task
Closure with full transparent audit trail

Platform Capabilities

Enterprise-grade features engineered for scalability.

Service Request Management

Create, view, update and delete service requests with precision.

RESTful API Architecture

Clean REST endpoints built on robust Jakarta REST / JAX-RS standards.

Authentication

Secure registration and login with HTTP response payload validation.

JWT Authorization

Token-based authentication with strict role-aware access control.

BCrypt Password Security

Passwords are stored as secure one-way hashes rather than plaintext.

Role-Based Access Control

Strictly enforced USER, TECHNICIAN and ADMIN permissions.

Technician Assignment

Administrators assign requests to specific technicians for resolution.

Workflow State Machine

PENDING → ASSIGNED → IN_PROGRESS → RESOLVED → CLOSED.

Search & Filtering

How FixFlow Works

One Platform. Three Powerful Experiences.

Specialized workflows injected via Role-Based Access Control.

USER

  • Create detailed requests
  • Track real-time status
  • Edit pending tickets
  • View complete history

TECHNICIAN

  • View assigned requests
  • Accept & start work
  • Manage active tasks
  • Mark requests resolved

ADMIN

  • Manage users & roles
  • Assign technicians
  • Monitor global operations
  • View platform statistics
